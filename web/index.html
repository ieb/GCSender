Getting started

The gcsender server owns the serial port; this page is only a window onto it. Reloading or closing the page never stops the machine, and any number of pages can be open. Pick the port (the C3018 shows as a CH340 / usbserial device) at 115200 baud and press Connect. GCSender reads $G, $$, $# and $I, and warns if $10 or $13 need changing.

The state badge shows Idle, Run, Hold, Door, Alarm… Unlock ($X) clears an alarm, Hold/Resume pause and continue, Door acts like the safety-door input, Reset stops everything (offsets and the parser state are restored afterwards).

Jogging

Jogging is in steps only: each click or key press moves exactly the chosen step (0.01 to 10 mm) at the chosen feed. Holding a key or button never repeats, so the machine cannot run on. Separate presses queue. A step that would leave the optional jog box (Settings → Application) is refused rather than shortened. Esc stops all motion.

Work zero

Jog to the work origin and use X0, Y0, Z0, XY0 or All 0 (G10 L20, kept in GRBL's EEPROM). Tick temporary (G92) for an offset that a reset clears. Go XY0 and Go Z0 move there, raising to safe Z first.

Probing & heightmaps

Probe Z touches off on a plate (thickness in the panel), optionally twice (fast, then slow), and sets work Z. Test checks the probe input first: the probe must read open, then touching when you close the clip on the plate.

For PCB work set a heightmap border (or Auto from a G-code file) and grid, then Probe map. The first point is the reference (Z0); every other point is relative to it. With a map loaded, tick heightmap in the Program panel to stream the compensated program; the server computes it. Maps can be saved, loaded and exchanged with Candle (.map).

Jobs

Open… (or drop a file) uploads a program to the server's library. A .zip of a board's programs becomes a set: pick it in Library…, check the order (back, align, front, drill, cut-out by default), load the first, and use Next after each one. Start runs it; Pause is a feed hold; Stop holds, resets and restores the offsets. To restart part-way, click a line in the table (or type it in from line): the server restores the program state at that line, raises to safe Z, moves above the start, starts the spindle with a dwell and plunges slowly. In the table and the 3D view, grey is done and violet is in GRBL's buffers.

On an M6, or an M0/M1 program pause (CAM tools often write a tool change as (MSG, …) + M0; its message is shown), the job stops and asks. Jogging and probing are allowed, then press Continue. On an error the machine is held and you choose Continue or Stop. The feed slider is an override: on GRBL 0.9 it takes effect after the moves already buffered (up to about 17).

Recovery

If the server stops or the USB link drops mid-job, the job comes back as interrupted. If the board was not reset, GCSender finds where it stopped and offers Resume here. If it was reset, the position is lost: re-establish work zero (and Z, at the heightmap origin if you use one), tick the two boxes and Resume with safe entry. Check the suggested line before resuming.

User commands

Buttons on the Machine tab run G-code on the server. {expr} inserts values: wx wy wz, mx my mz, prbx prby prbz, safez, with + - * / and min max abs. wait idle waits for the moves to finish. Esc stops a command.

Keyboard

Shortcuts other than Esc work when keyboard is ticked on the Jog panel and you are not typing in a field. Change them in Settings → Keyboard.

Safety

  • The red Stop and Esc are software stops. Keep the machine's power switch or an E-stop within reach.
  • Air-cut a new program (Z raised) before cutting. Check bounds in the Program panel against your stock.
  • GRBL 0.9 cannot cancel a single move; a long move runs to its end unless you Hold or Reset.

Troubleshooting

  • ALARM after connecting: homing is enabled ($22=1); home or Unlock.
  • No position in the State panel: set $10=3 (GCSender offers this).
  • Probe never triggers: use Test; check the clip and the A5 / probe pin wiring.
  • The board resets when the server starts: normal for this board (DTR). See Recovery.
  • Everything sent and received is in Logs → Serial transcripts.
  • Something wrong? Press 🐞 Report straight away and describe it: the report captures the state at that moment.
